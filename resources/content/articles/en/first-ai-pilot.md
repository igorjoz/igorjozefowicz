Start your first AI deployment with one problem whose outcome can be evaluated. Access to a model alone does not establish business value.

## Pick a specific workflow

For example, a support team writes similar replies repeatedly. A pilot could draft answers from company material for employee approval. Initially, it would not send replies automatically.

## Prepare data and ownership

- Assign a process owner and a person responsible for evaluating output.
- Collect representative, appropriately prepared examples.
- Decide which data may be sent to the model provider.
- Review permissions, retention and source freshness.

## Define pilot criteria

Before starting, decide what to assess: source consistency, completeness, corrections needed and cost per task. Compare results with the existing workflow using the same sample.

## Plan for failure

Define when a task goes back to a person. Users should be able to reject output and report problems. Decide how to disable the integration if it does not meet requirements.

## Decide after the pilot

Expand if the solution meets the agreed criteria. Otherwise improve the data, narrow the scope or stop the pilot. Each can be a useful outcome.
